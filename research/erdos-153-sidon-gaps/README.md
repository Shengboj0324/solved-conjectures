# Erdős–Sárközy–Sós conjecture

**Open.** [Issue #783](https://github.com/1337isnot1337/solved-conjectures/issues/783) tracks the exact statement of [Erdős Problem 153](https://www.erdosproblems.com/153), from [Erdős–Sárközy–Sós (1994), Problem 2, p. 345](https://real.mtak.hu/110604/1/1-s2.0-S0022314X84710407-main.pdf#page=17). For a finite Sidon set $A$, list its distinct unordered sums, allowing repeated summands, as $s_1<\cdots<s_t$. Must $t^{-1}\sum_{i<t}(s_{i+1}-s_i)^2$ diverge as $|A|\to\infty$? Translating an integer set makes the formulation with positive integers equivalent.

## What is proved here

- [Weak-limit profiles, original repository checkpoint](PROFILES.md). A hypothetical bounded-gap family has a limiting endpoint density $f$ with $\|f\|_2\le1$, and its energy bounds the integral of the reciprocal of $f*f$. The earlier work also gives a universal constant lower bound and a logarithmic lower bound near the minimum diameter.
- [Local lattice bounds](LATTICE-PROFILES.md). Differences of Sidon points force some unit sumset gaps, locally and with individual residue classes retained. The resulting bound imposes the exact convex envelope for integer gap lengths.
- [Modular extensions](MODULAR-EXTENSIONS.md). For each fixed $\varepsilon>0$, if an $n$-point Sidon set embeds into a cyclic perfect difference set of modulus $M\le n^{4-\varepsilon}$, its gap energy is $\Omega_\varepsilon(\log n)$. A bounded-gap counterexample family requires $M\gg n^4/\log^4 n$ whenever such an extension exists. The underlying discrepancy criterion also covers positive-relative-density subsets of the usual cyclic near-perfect constructions.
- [Four-point correlation barrier](CORRELATION-BARRIER.md). A synthetic bounded-gap lattice model meets leading-order sum/difference pair identities uniformly over every nonzero shift and all fixed continuous tests of the four endpoint values. It does **not** enforce coherent marks from one endpoint set and is not a Sidon counterexample.
- [Genuine sumsets with growing multiplicity](GENUINE-SUMSET-RELAXATION.md). An actual endpoint set of size $\Theta(\sqrt N)$ in $[0,N]$ gives bounded mean-square gap energy when its maximum unordered pair representation count is permitted to grow as $O(\log N/\log\log N)$.
- [No deletion or local repair](DELETION-BARRIER.md). For any fixed representation cap, the preceding random host typically contains no subset of comparable size satisfying it. The obstruction survives bounded movements and, with distinct parents, movements of size $N^\beta$ for a specified positive range of $\beta$.

- [Cyclic templates](CYCLIC-GAP-TEMPLATE.md) and [genuine cyclic Sidon sets](RUZSA-CYCLIC-SIDON.md). The latter give constant normalized squared-gap cost on the circle using classical Ruzsa sets.
- [Bounded-cost integer interiors](RUZSA-INTEGER-INTERIOR.md). Random integer lifts retain Sidon uniqueness and give bounded clipped cost in an arbitrarily large fixed fraction of the interior. Their two true edges cannot be ignored in the conjecture.
- [Two-endpoint budget](TWO-ENDPOINT-BUDGET.md). Sharing the available endpoint density mass between both ends gives an asymptotic lower bound of $22.13$.
- [Logarithmic whole-span upper bound](LOGARITHMIC-UPPER.md). For every large $n$ there is a genuine integer Sidon set of size $n$ and diameter $O(n^2)$ with mean square gap $O(\log n)$ on the whole span, including both endpoints. This supersedes the [earlier $O(\log^2 n)$ bound](WHOLE-SPAN-UPPER.md). The unit-residue window tail is squared by using independently randomized affine maps in two adjacent source rows.

- [Gap moments](GAP-MOMENTS.md). The construction has bounded whole-span moments of order $1<r<2$, and its square cost is necessarily logarithmic for every choice of its digits. This rules out a constant-cost square bound within that construction.
- [Weak Sidon lifts](WEAK-SIDON-LIFTS.md). The conjecture is unchanged if only off-diagonal uniqueness is required, because a binary tag preserves all points and bounded squared cost. A fixed tag alphabet also handles bounded-degeneracy all-distinct collisions, but fails on some capacity-two product sets.

The [finite arithmetic checker](check_lattice_identities.py) checks the lag identity, diagonal terms, integer convex gap cost, interval clipping, and the marked identity on small examples. It is not used as evidence for the asymptotic steps. No Lean work was performed in this campaign.

## Prior work and current limits

The source's theorem about the *largest* gap is not the mean-square statement. [Ruzsa (1996)](https://geodesic.mathdoc.fr/articles/10.4064/aa-77-4-353-359/) treats largest gaps and long subintervals. [Liu's corrected note](https://leon2k2k2k.github.io/erdos153_corrected.pdf) proves the near-maximum case; the [claim inventory](https://erdosproblems.ai/wiki/problems/additive_bases/E0153) records his withdrawn full argument and Kapoor's separate partial results. The [related isolated-sums theorem of Tsoukalas et al.](https://arxiv.org/abs/2605.22763) supplies the antecedent for the elementary short-shift quadruple rearrangement but has a different conclusion. The [Conjectures.io](https://conjectures.io/problems/erdos153-erdos-153?mode=counterexample), [TheoremDB](https://theoremdb.org/statements/erdos-problem-153/), and [qed.bot](https://qed.bot/erdos-since-the-wiki) records and searches by exact problem and paper title uncovered no further full proof/disproof. This is a bounded search, not a priority guarantee. The adjacent Sidon-extension and generalized-representation results are separately credited in the corresponding notes.

A proof still needs an endpoint restriction for **actual** Sidon families stronger than the weak difference capacity and leading-order four-point correlations. A disproof still needs a coherent algebraic construction with a cusp at both ends, unique sums, and quantitative control of void intervals across scales. The two benchmark paths now ruled out are thinning nearly uniform modular constructions and locally repairing the independent random cusp host. None of the results above resolves the conjecture. Changes are limited to this directory on the research branch.
