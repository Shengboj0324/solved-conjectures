# All complete finite order-type constructions on the first uncountable ordinal

Fix $r\ge1$. On the set of all increasing $r$-tuples from $\omega_1$, prescribe adjacency by any collection of joint order and equality patterns of two tuples, invariant under swapping the tuples. If the resulting graph has uncountable chromatic number, its finite subgraphs have unbounded Hall ratios. Thus allowing overlaps, arbitrary fixed arities and arbitrary finite unions of patterns still cannot supply the graph in Erdős, Hajnal and Szemerédi's Problem 2. [Original problem](https://users.renyi.hu/~p_erdos/1982-11.pdf) · [Vector-coloring and vertex-multiplicity argument](README.md).

**Proof.** Assign distinct infinite binary strings to the ordinals. Color each tuple by a prefix length distinguishing its $r$ entries and the ordered list of those prefixes. This preliminary coloring uses countably many colors. If two tuples in the same class share an ordinal, it necessarily occupies the same position in both lists. At least one such class induces an uncountably chromatic graph, since a countable union of countably colorable vertex sets is countably colorable.

Within that class separate the edges by the exact set $S\subseteq[r]$ of equal positions. There are finitely many possibilities. The union of finitely many countably colorable graphs on the same vertices is countably colorable by taking tuples of colors. Thus one of the graphs for a fixed $S$ still has uncountable chromatic number.

Every such edge preserves all entries in $S$. The graph is a disjoint union of fibers according to those entries, so some fiber has uncountable chromatic number. If $S$ is nonempty, put $j=\max S$ and write $\gamma$ for that fiber's fixed entry at $j$. There are countably many possibilities for the entire prefix through $j$, since $\gamma$ is a countable ordinal. Restrict to one prefix of uncountable chromatic number. Every edge in this restriction agrees throughout that prefix, so $S=[j]$. For empty $S$ use the empty prefix from the outset.

Now enlarge to all tuples with this fixed prefix, retaining only the original edge patterns with the same equal positions and otherwise disjoint tail entries. Dropping the preliminary coloring restriction can only increase the chromatic number. This tail graph is a subgraph of the original graph. It has disjoint-coordinate adjacency defined by strict order on a final segment of $\omega_1$. Every finite pattern in it admits arbitrary vertex multiplicities by replacing each of its finitely many tail coordinates by a long finite interval, in order and above the fixed prefix. The [multiplicity theorem](README.md) shows that its finite Hall ratios are unbounded. The same holds in the original graph. The case of several fixed arities follows by first restricting to one of the countably many vertex classes of a given arity.

The full-tuple domain matters for the enlargement step. On an arbitrary subfamily, newly chosen clones might be missing. A graph on an arbitrary subset of a second-countable Hausdorff space does satisfy the multiplicity obstruction when its edge relation is relatively open and its chromatic number is uncountable. Indeed the union of all countable basic open sets is countable. Remove it; every nonempty open neighborhood of a surviving point still contains uncountably many points. Openness now allows simultaneous disjoint neighborhoods for finite patterns, and hence arbitrary finite multiplicities.

More generally a countable cover of the edges by complete bipartite subgraphs gives the same conclusion for graphs of order at most the continuum. Give the vertices distinct binary strings and take the topology generated by the countably many prefix classes together with the vertex sides of the covering bicliques. This is second-countable and Hausdorff, and the covered edge relation is open. Hence any putative bounded-Hall example of order $\aleph_1$ also requires uncountably many complete bipartite subgraphs to cover its edges.
