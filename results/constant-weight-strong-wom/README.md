# En Gad–Yaakobi–Jiang–Bruck constant-weight strong WOM coding problem

**Lean status:** none.

A deterministic write-once memory encoder attains the known capacity with exact output weight for every state and message. Its decoder reads the written subset alone. Code construction, encoding and decoding take polynomial time. The same construction attains the optimal noiseless asymptotic rate for binary low-power cooling codes. [Original problem, Definition 12 and pp. 4215–4216](https://yaakobi.net.technion.ac.il/files/2015/11/16_RM_Rewriting_IT15.pdf).
